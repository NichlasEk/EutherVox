# Ebbas musik: YouTube 403, åtgärdat 2026-09-17

Symptom: Vox hittade titeln Ride of the Valkyries (`EUrvY1XggAI`), men
EutherWash rapporterade att ljudkällan inte kunde spelas.

Reproduktion utan robotuppspelning: samma resolver som gatewayen, följt av
två sekunders ffmpeg-avkodning på .186. Med yt-dlp 2026.07.04 returnerade
ljud-URL:en HTTP 403 och noll PCM-byte. Även alternativa m4a/webm-format
med hämtarens HTTP-headers nekades. Felet gick att reproducera på .88 också;
robotens högtalare, temabytet och länktolkningen var inte felkällan.

Uppgraderade yt-dlp till 2026.08.19 i gatewayens befintliga virtualenv och
låste versionen i uv.lock. Projektets lägsta version höjdes till 2026.8.19.
EJS/default-beroendena behålls. Inga webbläsarkakor, kontolösenord eller nya
YouTube-inloggningar behövdes.

Verifiering: exakt samma Wagner-video avkodades på .186 med exitkod 0 och
64 000 PCM-byte (2 sekunder, 16 kHz mono s16le). Inget ljud skickades till
Ebba. Gatewayen behöver startas om för att ladda den nya biblioteksversionen;
användaren kan därefter trycka Spela på Ebba igen för en färsk ljudadress.
Ingen ny Android-APK krävs.

Upstream har dokumenterat motsvarande 403-fel för äldre android_vr-klient:
https://github.com/yt-dlp/yt-dlp/issues/17456
